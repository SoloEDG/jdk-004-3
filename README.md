# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 模式与操作

顶栏可在「单人」与「双人协作」之间切换（仅在非战斗状态可切换，切换即重开一局）。

### 单人模式

- `W A S D` / 方向键移动，鼠标可指向射击，否则武器自动锁定最近敌人。
- `ESC` / `P` 暂停，切窗自动暂停。

### 本地双人协作

- 玩家一：`W A S D` 移动，鼠标指向射击。
- 玩家二：方向键移动，自动索敌。
- 两人共享同一份敌潮、弹幕与掉落，但移动、装备、升级、经验与遥测各自归属独立面板。
- 经验晶体由所有在线角色**平均分配**，不存在最后拾取者独享；治疗包只回复拾取者。
- 任一人升级都会冻结整场战斗，两人按队列依次完成各自的升级选择后才解冻。
- 一方倒下后进入离线状态，不再获得经验或升级；队友进入其红色危险区并持续停留 2.5 秒即可救援，离开范围会中断并清零进度。只有双方同时倒下才会结算。
- 重开（或切换模式）会清除上一局的救援进度、待升级队列与双方输入。
